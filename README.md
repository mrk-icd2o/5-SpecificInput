# Lab 5 - Specific Input

You will be writing your code in `sketch.js` within the main folder - not the `example/` folder.

To run your code open `index.html` and then click on the *Go Live* button in the bottom right.  This will open a browser page, and should refresh every time your work saves.

Re-create [this program](https://openprocessing.org/sketch/975902/embed/?plusEmbedHash=31789e3f&userID=175929&plusEmbedTitle=true&show=sketch):

- Use the arrow keys (or an alternative like WASD) to move the rectangle.

- The rectangle must stay within the bounds of the screen.

- When clicking **inside** the rectangle, it turns green.
